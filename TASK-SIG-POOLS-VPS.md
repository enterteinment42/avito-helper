# Задача серверу: положить пулы подписей в документ настроек avito-helper

Поставлена 16.10.2026 (Windows-сессия, решение Дениса). Исполнитель — сессия с доступом
к хранилищу `/api/avito-sync/` в `poigraem-backend` (зона Claude1).

## ⚠️ Начинать только после слова Дениса «Ctrl+F5 сделан везде»

Документ `settings` каждое устройство перезаписывает **целиком** при любой правке настроек,
версии у него нет. Страница без `syncPullSigPools` (старше коммита 16.10 с этой задачей)
про пулы не знает и первой же отправкой сотрёт их на сервере. Новая страница с пустым пулом
сама заберёт подписи с сервера перед отправкой и дальше шлёт их вместе с настройками.

## Что сделать

1. Сохранить копию текущего документа `settings` рядом (имя с датой) — для отката.
2. В документе `settings` в `data.settings` задать **только два ключа** — `sigGame` и `sigSub` —
   значениями из JSON ниже (массивы строк; перевод строки внутри варианта — `\n`).
   Всё остальное (`data.cats`, `data.catalogs`, прочие `data.settings.*`, `presets`, `queue`,
   `cv`, `scenes`) не трогать. Если в `data.settings` есть `sigPool` / `sigCats` (первая версия
   15.10) — удалить.
3. Обновить `updated` документа так же, как это делает обычная запись.
4. Проверить: `GET /api/avito-sync/settings` → `data.settings.sigGame` — 7 строк,
   `data.settings.sigSub` — 3, прочие ключи совпадают с копией из п. 1.
5. Отметить `[x]` ниже с датой и запушить; Денису — что сделано.

Источник — `data/sig-pools-2026-10-15.txt` (на сервере его нет из-за sparse-checkout),
тексты утверждены Денисом 16.10.

- [ ] Пулы положены, проверка п. 4 пройдена
