**Что сделано:**

### 2026-05-27 — Диагностика CORS

**Что сделано:**
- Диагностирована ошибка `Failed to fetch` при запуске `avito-helper.html` из `file://`
- Причина: браузер отправляет `Origin: null` для `file://`-протокола, сервер не имеет этого в whitelist CORS

**Что решили:**
- Итоговое решение: файл открывается через GitHub Pages — CORS не нужен
- `npx serve` как быстрый вариант для локальной отладки
