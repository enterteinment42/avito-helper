# Задача Windows-сессии: переезд сайта с GitHub Pages на Netlify

Поставлена 16.10.2026. **Статус: отложена — не начинать без слова Дениса.** Порядок решён 16.10: **после** `TASK-SERVERIZE-WINDOWS.md` — тогда ловушка 1 (сырьё в localStorage) снимается.

## Зачем

Репозиторий `enterteinment42/avito-helper` публичный (решение 13.08.2026: бесплатный
GitHub Pages работает только с публичным). С тех пор в журналах, архивах, `TASK-…` и тестах
накопились IP серверов, имена VPN-узлов, сведения о людях в РФ. Цель — сделать репозиторий
приватным, а сайт отдавать с Netlify (бесплатно работает с приватным репозиторием).

Альтернатива, которую Денис держит в уме: GitHub Pro (~$4/мес) — адрес не меняется,
переезд не нужен.

## Что учесть — три ловушки

1. **Сырьё живёт в `localStorage` и привязано к адресу (origin).** На `*.netlify.app` инструмент
   откроется пустым на всех устройствах. Корзина и кладбище в файл-бэкап не входят.
   Главное правило проекта: правка, способная стереть сырьё, закрывается тестом до коммита.
2. **CORS-список прокси** в `poigraem/backend/server.js` (зона Claude1) пускает только
   `enterteinment42.github.io`, `poigraem.shop` и др. Новый адрес Netlify туда не входит —
   без правки «Failed to fetch» на любой генерации (Bug #10, 13.08.2026).
3. **Закрытие репозитория не убирает уже опубликованное:** история была открыта с 13.08,
   копия до 13.07 — в публичной истории репозитория магазина.
