# avito-helper — справочник

Устройство инструмента: постановка задачи, архитектура, модули, провайдеры,
соглашения, каталог, правила Авито, эталоны стиля. Вынесено из `CLAUDE.md`
22.09.2026 — в автозагрузку не входит, читается по необходимости.

---

## Проблема

Продавец на Авито (лучший в регионе, 60+ объявлений подписок + 50-150 игр). Для конверсии нужно:
- Несколько объявлений одной подписки/игры в разных регионах
- Уникальные названия и описания для каждого (чтобы не банили за дубли и для A/B)
- Разные обложки (коллажи для подписок, вариации для игр)

API Авито не даёт ключей, платная автоматизация неэффективна → нужен инструмент для **подготовки контента**, который потом копипастом вставляется на Авито.

## Архитектура

- **Формат:** единый HTML-файл (как артефакт), открывается локально в браузере
- **AI:** Claude API через прокси `https://api.poigraem.shop/api/claude` (POST, принимает стандартный Anthropic формат)
- **Хранение:** localStorage для базы объявлений, истории генераций, настроек
- **Стиль:** единый с проектом «Поиграем» — Literata + JetBrains Mono, accent: #B45309, teal: #0F766E

## Модули (в порядке приоритета)

### 1. Генератор описаний и названий (MVP)

**Что делает:** по выбранной подписке/игре генерирует 3-5 уникальных вариантов названия + описания для Авито.

**Интерфейс:**
- Выбор категории: игровая подписка / AI-подписка / цифровой товар / игра
- Для игровой подписки: тип, платформа, срок, цена, список ключевых игр
- Для AI-подписки: сервис, срок, цена, ключевые фичи
- Для цифрового товара: название, описание, цена
- Для игры: название, платформа, цена, жанр
- Выбор стиля: продающий / информативный / краткий / развёрнутый
- Кнопка «Сгенерировать» → 3-5 вариантов названий + описаний
- Кнопка копирования одним кликом (отдельно название, отдельно описание)
- Возможность «перегенерировать» конкретный вариант
- Сохранение удачных вариантов в избранное

**Промпт для Claude (системный):**

```
Ты — эксперт по созданию объявлений на Авито для продажи цифровых товаров: игровых подписок (PS Plus, EA Play, Game Pass), AI-подписок (Claude Pro, ChatGPT, Google AI Pro, Cursor, Antigravity) и цифровых игр.

ЗАДАЧА: генерировать УНИКАЛЬНЫЕ варианты объявлений для одного и того же товара. Каждый вариант должен отличаться не рерайтом, а СТРУКТУРНО — как будто его писал другой продавец.

ПРАВИЛА НАЗВАНИЙ (макс. 50 символов с пробелами):
- Обязательно: название товара + крючок (фишка, выгода, топ-игра, цена за месяц)
- Варьировать: какую игру/фичу вынести в название, как подать цену, какие слова использовать
- Можно объединять подписки: "PS+Deluxe|Extra" или "Все подписки PS+" — это отдельный тип объявления
- Примеры стилей названий:
  * С топ-игрой: "Подписка PS+Extra(Человек Паук 2,GTA5)пс5"
  * С ценой за месяц: "PS Plus Extra 12мес — от 608₽/мес пс4 пс5"
  * С эмоцией: "PS+Deluxe 405+игр — прокачай свою консоль"
  * С фичей: "Claude AI Pro — самая умная нейросеть"
  * Объединённое: "PS+Deluxe|Extra(Хогвартс,гта5)пс4,пс5"

ПРАВИЛА ОПИСАНИЙ:
- Использовать эмодзи (⚡️✅💲🎮🚀🧠🔥), но в разных комбинациях
- Список ТОП-игр/фич — обязательный скелет, но порядок и набор варьировать
- Цены подавать по-разному:
  * Просто цена: "3000 руб за 12 мес"
  * Цена за месяц: "всего 250₽/мес"
  * Сравнение: "дешевле чашки кофе"
  * Экономия: "экономия 40% от помесячной"
- Структуру описания менять:
  * Начать с боли → решение → фичи → цены
  * Начать с цены → что получишь → фичи
  * Начать с списка игр → преимущества → цены
  * Начать с эмоции/метафоры → содержимое → цены
- Стили текста: дерзкий/молодёжный, деловой/информативный, восторженный, минималистичный
- Для AI-подписок: описывать конкретные инструменты и юзкейсы, не абстрактно

ВАРИАТОРЫ (что менять между объявлениями):
1. Название: другая игра/фича в крючке
2. Структура описания: другой порядок блоков
3. Подача цены: помесячная / общая / со скидкой / сравнение
4. Набор игр в списке: ротация из полного каталога
5. Эмодзи: другой набор
6. Тон: от дерзкого до делового
7. Объединение: только Extra / только Deluxe / обе вместе / все PS+
8. Регион: влияет на цену доставки/активации если есть

ФОРМАТ ОТВЕТА (JSON):
{
  "variants": [
    {
      "id": 1,
      "title": "название до 50 символов",
      "title_length": число,
      "description": "полное описание",
      "style": "дерзкий|деловой|восторженный|минимальный",
      "price_format": "помесячная|общая|сравнение|экономия",
      "hook": "что вынесено в крючок названия",
      "structure": "боль→решение|цена→фичи|список→преимущества|эмоция→содержимое"
    }
  ]
}
```

**Входные данные для промпта (передаются в user-сообщении):**
- Категория товара и конкретный продукт
- Платформа(ы)
- Доступные сроки и цены
- Список игр/фич (полный, из которого AI выбирает)
- Сколько вариантов нужно
- Какие уже существующие названия исключить (из базы)
- Дополнительные указания (объединить с другой подпиской, сделать акцент на...)

**Ключевая идея:**
Это не просто генератор текстов. Это КОМБИНАТОРНЫЙ ВАРИАТОР — он должен понимать, что каждое объявление собирается из осей вариации (название × структура × подача цены × набор игр × тон × эмодзи × объединение), и выдавать варианты из РАЗНЫХ точек этого пространства, а не соседних.

**Важно:**
- Названия СТРОГО до 50 символов — проверять длину
- Описания — реально разные по структуре, не рерайт одного и того же
- Учитывать ограничения Авито: длина названия, запрещённые символы, правила площадки
- Для подписок — особенно сложно, т.к. одну подписку нужно описать 5-10 разными способами
- AI-подписки — отдельная аудитория (разработчики, дизайнеры, студенты), другой язык

### 2. Конструктор обложек-коллажей

**Что делает:** собирает обложки из картинок игр в готовый коллаж для Авито.

**Интерфейс:**
- Загрузка обложек игр (drag & drop или выбор файлов)
- Выбор раскладки: сетка 2×2, 3×2, 3×3, полоски, диагональ, свободная
- Наложение текста: название подписки, цена, бейджи ("ЛУЧШАЯ ЦЕНА", "100+ ИГР")
- Настройка фона, рамок, теней
- Превью и скачивание в нужном разрешении (Авито: 1:1 или 4:3)
- Рандомизация: кнопка «другой вариант» меняет раскладку/фон/порядок

**Для игр:**
- Взять одну обложку и сделать вариации: разные рамки, фон, стикер с ценой, платформа-бейдж
- Быстрая генерация 3-5 вариантов одним кликом

**Технически:** Canvas API, всё клиентское, без бэкенда.

## AI-провайдеры и модели

Приложение поддерживает переключение между провайдерами и моделями. **Все запросы идут через прокси на VPS** — прямые вызовы из России блокируются (IP + DPI), прокси обходит это (как уже сделано для основного Поиграем).

### Поддерживаемые провайдеры

| Провайдер | Модели | Эндпоинт прокси | Статус |
|-----------|--------|-----------------|--------|
| Anthropic (Claude) | Sonnet 5 (по умолчанию), Opus 5, Haiku 4.5 | `/api/claude` | ✅ работает |
| OpenRouter | любые (зоопарк моделей) | `/api/openrouter` | ⚠️ эндпоинта нет на VPS, см. Bug #9 |

**Приоритет по умолчанию:** Claude Sonnet 5 (`claude-sonnet-5`). Haiku 4.5 — для дешёвых черновых генераций, Opus 5 — когда нужен максимум. OpenRouter — для экспериментов, но пока не работает.

⚠️ **Модели различаются НАБОРОМ ПАРАМЕТРОВ ЗАПРОСА, а не только качеством** (сессия 2026-09-06). На моделях 5-го поколения и Opus 4.7+ параметр `temperature` **удалён и возвращает 400** — из-за этого «Opus 4.7» в списке ронял любую генерацию, пока никто его не выбирал. Поэтому в коде есть таблица `MODEL_CAPS` (`sampling` / режим размышления / версия инструмента веб-поиска) и `modelCaps(id)`; неизвестная модель получает самый осторожный набор — такой запрос примут и старые, и новые. **При добавлении модели в `CLAUDE_MODELS` обязательно добавлять строку в `MODEL_CAPS`**, иначе она молча поедет на осторожных дефолтах. Смена дефолтной модели требует и строки в `MODEL_MIGRATION` — иначе у Дениса в `localStorage` останется снятая модель, а селект покажет пустоту. Размышление (`thinking: {type:'adaptive'}`) просится точечно через `opts.thinking` — сейчас у распознавания по фото и поиска цены; оно тратится из `max_tokens`, поэтому лимиты там подняты.

Ключи хранятся в `.env` на VPS (не в браузере): `ANTHROPIC_KEY` (проверено), и, по аналогии с соседними ботами на том же VPS (`chat-bot`, `editorial-bot`), вероятно `OPENROUTER_API_KEY` — не `OPENROUTER_KEY`, как было записано здесь раньше (сессия 2026-09-06 нашла и поправила это по локальным копиям кода ботов, но сам `.env` на сервере в эту сессию не открывался). У соседних ботов этот ключ используется ТОЛЬКО для текста — вызов image-моделей с ним ещё не проверялся (нужен для направления 2б, см. «Текущий фокус»).

### Абстракция вызова (клиент)

```javascript
// Настройки провайдера хранятся в localStorage
const AI = {
  provider: 'claude',      // 'claude' | 'openrouter'
  model: 'claude-sonnet-4-20250514',
};

async function callAI(messages, system, opts = {}) {
  const provider = opts.provider || AI.provider;
  const model = opts.model || AI.model;

  if (provider === 'claude') {
    const res = await fetch('https://api.poigraem.shop/api/claude', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model,                    // claude-sonnet-4-... | claude-haiku-...
        max_tokens: opts.max_tokens || 4000,
        system,
        messages,                 // Anthropic-формат
      })
    });
    const data = await res.json();
    return data.content?.map(b => b.text).join('\n') || '';
  }

  if (provider === 'openrouter') {
    // OpenRouter = OpenAI-формат: system идёт первым сообщением
    const orMessages = system
      ? [{ role: 'system', content: system }, ...messages]
      : messages;
    const res = await fetch('https://api.poigraem.shop/api/openrouter', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model,                    // напр. 'anthropic/claude-3.5-sonnet', 'google/gemini-...', 'meta-llama/...'
        max_tokens: opts.max_tokens || 4000,
        messages: orMessages,
      })
    });
    const data = await res.json();
    return data.choices?.[0]?.message?.content || '';
  }
}
```

### UI переключения

- Селектор провайдера: Claude / OpenRouter
- Селектор модели (зависит от провайдера):
  - Claude: Sonnet (default), Haiku
  - OpenRouter: текстовое поле или список (можно вписать любую модель вручную)
- Настройка сохраняется в localStorage
- Можно задавать модель на уровне отдельной задачи (черновики — Haiku, финал — Sonnet)

**Важно:** форматы ответов разные — Claude отдаёт `content[].text`, OpenRouter `choices[0].message.content`. Абстракция `callAI()` это скрывает.

## Правила и ограничения Авито

### Лимиты
- **Название:** строго до 50 символов с пробелами
- **Описание:** лимит очень большой — для наших объявлений не актуален
- **Фото:** до 10 штук на объявление; предпочтительно вертикальные

### Запрещено (снимают объявление)
- Ссылки на внешние ресурсы, QR-коды
- Упоминание других каналов связи («пишите в Telegram», «WhatsApp» и т.п.)
- Любые намёки на продажу аккаунта — писать нельзя ни в каком виде

### Обязательные фразы
- **Для игр:** «оформляется в цифре» — обязательно
- **Для игр и подписок:** указывать платформы (PS4/PS5, Xbox и т.п.) — и в названии, и в описании

### CTA (разрешённые)
- Отсылка в личку Авито — не банят: «Не нашли нужную игру? Пишите в личку — у нас большой каталог»
- Мягкий апсейл в конце объявления: упоминание что есть другие игры и подписки

### Как Авито определяет дубли
По фото, по названию и по тексту описания. Одинаковые фразы (особенно длинный список игр) — прямой путь к бану. Поэтому:
- Разные объявления = разные точки в пространстве вариаций
- В одном регионе не размещать слишком похожие объявления

### Оси рандомизации (примеры реальных замен)
**Названия игр** — одно и то же можно написать по-разному:
- `Red Dead Redemption 2` / `RDR 2` / `рдр2` / `rdr2`
- `FC 26` / `FC26` / `FIFA 26` / `ФИФА 26` / `фифа26`
- `UFC 5` / `ЮФС 5` / `юфс5`

**Названия подписок** — варьировать в названии И в теле:
- `PS+ Extra` / `ПС+ Экстра` / `PS Plus Extra` / `ПС Плюс Экстра` / `подписка пс плюс`

**Платформы** — тоже разные форматы:
- `PS4/PS5` / `ПС4,ПС5` / `пс4 пс5` / `для пс4 пс5` / `подписка на пс4,пс5`

**Список игр** — базовый скелет + ротация:
- Не менять весь список, но менять порядок, набор «дополнительных» игр, стиль оформления (запятые / с новой строки / через dash)

### SEO: по каким запросам ищут
Люди ищут игры разными способами:
- На русском: «человек паук», «гта 5», «ведьмак», «призрак цусимы»
- Транслит: «spiderman пс5», «gta5 пс4», «witcher 3»
- Аббревиатуры: «rdr2», «rdr 2», «гта», «мк11»
- С платформой: «игры пс5», «подписка пс плюс», «game pass xbox»
- С ценой: «купить ps plus дёшево», «ps plus 12 месяцев»

Генератор должен учитывать эти варианты при формировании описания.
