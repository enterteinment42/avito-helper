# avito-helper — указатель

Инструмент подготовки объявлений для Авито: генератор описаний и названий,
конструктор обложек-коллажей, хранилище эталонов и финальных текстов.
Работает в браузере, серверных процессов нет.

Этот файл грузится в КАЖДОЙ сессии, поэтому здесь только то, без чего нельзя
начать: правила, открытые задачи строками и команды. История и справка — ниже.

| Файл | Что внутри | Когда читать |
|---|---|---|
| `CLAUDE-LOCAL-FOCUS.md` | чем занимаемся сейчас | грузится сам, импортом |
| `CLAUDE-LOCAL.md` | журнал сессий на Windows: лог и прежний «Текущий фокус» целиком | нужен ответ из прошлого |
| `CLAUDE-REFERENCE.md` | устройство инструмента, модули, провайдеры, правила Авито, эталоны стиля, разбор журнала самообучения | нужна справка по устройству |
| `AUDITS-OPEN.md` | аудит Fable №2 и консилиум 29.09 (`CONSILIUM-2026-09-29.md`) — незакрытые находки | берёшь находку в работу |
| `RUNBOOK.md` | что делать при аварии: пропажа сырья, плашки записи, старая версия, ответы сервера | что-то сломалось |
| `PLAN-FOTOR.md` | план сближения с Fotor: оформление обложек | берёшь его часть в работу |
| `AUDITS-ARCHIVE.md` | закрытые аудиты и находки | `/session-audits-archive` |
| `SESSIONS-ARCHIVE.md` | записи лога старше пяти последних | `/session-archive` |

**Серверная сторона — в репозитории, папка `vps/`** (указатель, журнал `CLAUDE-VPS.md`,
фокус): разбор журнала самообучения (`~/avito-journal`) и всё серверное. На VPS — клон со
sparse-checkout (`vps/` + `TASK-*.md`), `~/avito-helper` — ссылка на `vps/`. ⚠️ **`vps/` ведёт
только серверная сессия; Windows читает, не правит.** Журналы равноценны: **пиши в журнал
своей машины.** Задачи — файлы в корне: `TASK-…-VPS.md` серверу, `TASK-…-WINDOWS.md` сюда;
сделанное — `[x]` с коммитом.

**Как понять, где ты — по пути рабочего каталога:**
`D:\His Apps\avito-helper` (любой windows-путь) — Windows, журнал `CLAUDE-LOCAL.md` здесь, рядом.
`/home/ubuntu/avito-helper` или `/home/ubuntu/avito-helper-repo/vps` — сервер, журнал `vps/CLAUDE-VPS.md`.
⚠️ Не угадывай по операционной системе — смотри путь.

Импорт: @CLAUDE-LOCAL-FOCUS.md

## Что здесь нельзя сломать

⚠️ **Главное правило проекта, заданное Денисом прямо:** сырьё (эталоны, финалы)
и промпт — единственное невосполнимое, «из них можно слепить что угодно».
**Любая правка, способная их стереть, закрывается тестом до коммита.**

⚠️ **Корзина и кладбище не входят в файл-бэкап.** Удалённое живёт только
в `localStorage['avito_trash']` / `avito_deleted` и в серверном документе `voice`.

⚠️ **Три механизма потери записей уже случались** (найдены и исправлены 14.09):
близнецы по ключу-содержимому, затирание из соседней вкладки, удаление записи
с финалом без предупреждения. Разбор целиком — в `CLAUDE-LOCAL.md`, 14.09.

## Команды

**Расширенный аудит** («прогнать аудит», «свежий взгляд», после крупных правок `avito-helper.html`) — skill **`avito-helper-audit`** (`.claude/skills/avito-helper-audit/SKILL.md`), методика в нём. Во время аудита правок не делать: диагноз, отчёт в чат, раздел в CLAUDE.md.

**`/session-end`:**
1. Обнови `## Текущий фокус` (`CLAUDE-LOCAL-FOCUS.md`).
2. НОВУЮ запись — В НАЧАЛО `## Лог сессий` в журнале своей машины (существующие не редактировать): дата, что сделано, что решили, новые баги (файл + описание), открытые вопросы, что осталось.
3. Записей больше 5 — самые старые в начало `SESSIONS-ARCHIVE.md`, на их месте строка-указатель.
4. Полностью закрытое за сессию (аудит, находка, пункт бэклога) — в `AUDITS-ARCHIVE.md` с пометкой «✅ закрыт, сессия N, коммит(ы) …», здесь строка-указатель. ⚠️ Код готов, но не проверено — это НЕ закрытие.
5. `git status --short` и `git log --branches --not --remotes --oneline` — показать Денису, напомнить. Не коммитить без явной просьбы.
6. Спроси: «Что ещё зафиксировать?»

**`/session-start`** (или новый чат про проект): прочитай фокус и 2–3 последние записи лога → «В прошлый раз остановились на […]. Открыто […]. Следующий шаг был […].» → «Продолжаем с этого или новое направление?»

**`/session-archive`** — прочитай `SESSIONS-ARCHIVE.md`; **`/session-audits-archive`** — `AUDITS-ARCHIVE.md`. Резюмируй решения, баги, паттерны → «Что именно ищем?»

## Объём файлов памяти

⚠️ Указатель и файл фокуса грузятся автоматически — держим в пределах **12 КБ на файл**.
Фокус: не больше **3 блоков**, ничего **старше самого свежего блока в файле на 30 дней**, выбывшее уходит в журнал.
**Нарратив в фокус не дописывают** — одна тема, короткий блок, подробности в журнале.
До прополки 22.09.2026 этот файл весил 212 КБ и съедал 55 600 токенов в каждой сессии.
