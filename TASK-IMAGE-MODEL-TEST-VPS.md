# avito-helper — проба image-моделей для «Товара в интерьере» (23.11.2026)

Для серверной сессии. Windows-сессия `.env` не читает и ключ не видит.

## Зачем

Денис хочет оставить GPT Image, но сравнить текущую модель с новой и с Nano Banana.
Проба: одна и та же фотка (Xbox Series S + геймпад), сцена «🎮 Игровой сетап», уточнение
«на телевизоре заставка GTA VI», **качество high**, 3:4. Денис гоняет её сам в инструменте
(`avito-helper.html` → «Товар в интерьере»), с сервера нужна только смена модели.

## Что сделать

Порядок строгий, по одной модели за раз. После каждой — написать Денису «готово, гоняй» и ЖДАТЬ его «следующая».

0. Записать, что стоит в `OPENROUTER_IMAGE_MODEL` сейчас (ожидаем `openai/gpt-image-2.5-sunburst`) — это и есть эталон и точка возврата.
1. `openai/gpt-image-2.6-sunburst` (новейшая у OpenAI, по странице OpenRouter сборка 04.11; $8/M вход, $30/M выход картинкой).
2. `google/gemini-nano-banana-2.1` (Google, 06.10).
3. По желанию Дениса: `openai/gpt-image-2.6-flare`, `google/gemini-3.1-flash-image`.
4. **Вернуть** значение из п. 0, если Денис не скажет оставить другое. Не оставлять пробную модель молча.

## Ловушки

- ⚠️ Маршрут `/api/image` и белый список параметров писались под GPT Image (`input_references`
  в единственном числе, `aspect_ratio`, `quality`). У Gemini-моделей форма запроса/ответа может
  быть другой (chat/completions с `modalities`, картинка в `message.images`). Если `/api/image`
  с ней не работает — НЕ переписывать маршрут молча: сказать Денису, что именно ломается, и
  спросить, нужен ли отдельный адаптер.
- `quality` у не-OpenAI модели может игнорироваться — отметить, если так.
- Смена модели через `.env` требует перезапуска сервиса (см. `RUNBOOK.md`).
- После пробы вернуть Денису: какой id стоял, что вернул сервер (коды, ошибки), по возможности стоимость запроса.
