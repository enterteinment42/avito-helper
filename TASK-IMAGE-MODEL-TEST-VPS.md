# avito-helper — проба image-моделей для «Товара в интерьере» (23.11.2026)

Для серверной сессии. Windows-сессия `.env` не читает и ключ не видит — **прогон делает сервер сам, Денис в инструменте ничего не гоняет.**

## Зачем

Денис хочет оставить GPT Image, но сравнить текущую модель с новой и с Nano Banana.
Проба: фотка Xbox Series S + геймпад, сцена «🎮 Игровой сетап», «на телевизоре заставка GTA VI», 3:4.

## Что сделать

1. **Фото.** В git оно НЕ кладётся (на фото комната Дениса, а репозиторий пока не переехал в приватный). Попросить Дениса положить файл на сервер, например `~/image-test/xbox.jpg` (scp / как ему удобно). Денис в курсе, что без этого не стартовать.
2. **Скрипт** `tests/image-model-test.mjs` (в этом же коммите, секретов в нём нет) — шлёт один и тот же промпт (копия `stagedPrompt()` + `REALISM_ROOM`) напрямую в OpenRouter chat/completions по очереди на три модели:
   - `openai/gpt-image-2.5-sunburst` — эталон, то, что стоит сейчас;
   - `openai/gpt-image-2.6-sunburst` — новейшая у OpenAI (сборка 04.11, $8/M вход, $30/M выход картинкой);
   - `google/gemini-nano-banana-2.1` — Google, 06.10.
   Запуск: `node tests/image-model-test.mjs ~/image-test/xbox.jpg`. Ключ берётся из окружения сервиса (`OPENROUTER_AVITO_KEY`), в вывод и файлы не пишется. Картинки — в `./image-test-out/`.
3. **Отдать Денису** три файла (способ — по договорённости с ним) и строку вывода по каждой модели: секунды, стоимость, ошибки.
4. `OPENROUTER_IMAGE_MODEL` в `.env` и работающий `/api/image` **не трогать** — это проба, а не смена модели. Менять боевую модель — только после слова Дениса.

## Ловушки

- ⚠️ Скрипт использует chat/completions с `modalities` и `image_config`. Рабочий `/api/image` ходит другим маршрутом (`input_references`, `quality`). Схему запроса для chat/completions никто живьём не проверял — если модель вернула ошибку формата, поправить скрипт и сказать Денису, а не молча пропускать модель.
- Качества `high` у скрипта нет (параметра нет в chat/completions). Если у OpenAI-моделей это влияет на результат — отметить; тогда сравнение с «Финалом» из инструмента будет неточным, и это надо озвучить.
- Если у сервера ключ в другой переменной — поправить строку `KEY` в скрипте и сказать Денису.
