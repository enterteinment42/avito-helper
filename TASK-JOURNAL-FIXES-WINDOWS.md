# avito-helper — правки для Windows-сессии

Источник — первый разбор журнала самообучения 15.10.2026 (`CLAUDE-VPS.md`, запись
за 15.10). Выборка: 14 различных опубликованных объявлений, все правлены человеком,
медиана доли правки 0.35. Числа ниже — «из 14», дубли `posted`/`edited` сняты.

Лежит в корне репозитория `enterteinment42/avito-helper`; серверные журнал и фокус — в `vps/`.
Отметь сделанное здесь `[x]` с коммитом и запушь — серверная сессия сверит по следующему
разбору журнала, изменилось ли поведение.

## Генерация текста

- [x] **Подпись продавца — константой, а не генерацией.** `63a1014`. По решению Дениса —
  не одна константа, а **пул вариантов** (он каждый раз меняет пару слов): ⚙ Настройки →
  «✍ Подпись продавца», по кругу ко всем путям генерации, галочки по категориям (по
  умолчанию игры, игровые и AI-подписки), 🔄 в карточке. Модели не показывается —
  вырезается из примеров, перефраза и ротации. ⚠️ **Пул пока пуст** — ждёт вариантов из
  журнала (запрос Claude1, 15.10); до наполнения поведение не меняется.
  Исходная формулировка: Человек дописывает в конец
  постоянный блок («зачем обращаться ко мне… честная цена… я геймер… репутация»):
  9 из 14 итоговых текстов, 340–540 знаков, во всех играх с 12.09. Отсюда почти всё
  раздувание (медиана 737 → 1022 знака). Предложение: поле «подпись» в настройках
  (лучше — по категории: у подписок её не было), код приклеивает к описанию после
  генерации. Модели её не показывать, чтобы не пересказывала. Из 165 эталонов
  подпись есть только у 4 — бот её и не мог выучить.
- [x] **«в цифре» → «онлайн».** У бота «оформляется в цифре» в 12 из 14, у человека
  0; «онлайн» — 6 → 11. Правило в промпт + (по желанию) замена кодом.
  `63a1014`: промпт (прямой запрет «в цифре», правило «аккаунт», детали игры, предзаказ),
  обязательная фраза Сканера для игр теперь «онлайн», плашка инфографики. Замены кодом нет.
- [x] **Заголовок без поэтического хвоста.** `63a1014`: схема «НАЗВАНИЕ — ПРОДАЮЩИЙ ДОВОД
  (ПЛАТФОРМЫ)» в системном промпте (его же берут шаг заголовков и `alt_titles`), образные
  хвосты в запрете, напоминание в `alt_titles` и перефразе. Схема бота «Название платформы — образ»
  («— ярость мутанта», «— вампир на один день», «— на одном дыхании») — 12 из 14;
  у человека 1. Человек ставит продающий довод: «от создателей Ведьмака»,
  «главное событие года», «футбольная новинка», «новый сезон Ultimate Team»;
  платформы — в скобках в конце (5 из 14: «FC 27 - футбольная новинка (PS4,5/Xbox)»).
  Поправить инструкцию к заголовкам и `alt_titles`.
- [x] **Не терять PS4.** `63a1014`: платформы приходят только из чипов формы (у PS Plus
  PS4 ставится сама) — теряла модель. Правило «все платформы из входных данных» +
  предупреждение Сканера, если PS4 в форме есть, а в тексте нет. Человек дописывал PS4, которую бот не упомянул: FC 27,
  PS Plus Extra ×2. Проверить, откуда бот берёт список платформ (вероятно, сужает
  до current-gen); если игра выходит на PS4 — называть.

## Журнал

- [x] **`cv_variants` спамит.** `63a1014`: причина — `cvReDraw` на каждом движении
  слайдера перерисовывал варианты, а функция вариантов писала событие. Теперь пишет
  только кнопка «✨ 4 варианта». 15.10: 256 событий за 2 минуты, медианный интервал
  16 мс, все одинаковые (`mode:game, infog:false`) — 27% всего журнала. Похоже на
  запись на каждый рендер. Писать по действию человека или с дебаунсом/дедупом.
- [x] **Дубли `posted`/`edited`.** `63a1014`: `posted` (все 4 пути) и `edited` несут
  `rec` = `_uid` записи Истории — **разбору склеивать по `rec`**; повтор с тем же `eid`
  = переотправка. Переспрос перед повторным «Размещено» в клиенте уже есть; оба дубля
  (10.09, 12.09), вероятно, старше него — дату не сверял.
  Исходная формулировка: Одна публикация пишется 2–3 раза (Claude Pro
  Сыктывкар 10.09 — 3 раза, Wolverine 12.09 — 2). Если это повторный клик «выложил» —
  пусть пишется, но с тем же ключом публикации, чтобы разбор склеивал; если это
  повторная отправка — дедуп на клиенте.

## Обложки (от Дениса, 15.10, не из журнала)

- [ ] **Фон не виден в основной редактируемой обложке.** В окне предпросмотра
  (основной холст, который правится) фон не подставляется и не виден, а в четырёх
  дополнительных вариантах ниже фон есть. Разобрать, почему основной холст рисуется
  без фона; варианты рисуют его правильно — можно взять оттуда.
  Гипотеза, не проверена: у основного холста отступ `cv.gamePad` по умолчанию 0,
  и картинка «cover» закрывает фон целиком; у вариантов 2–4 свой `pad` 24–36,
  поэтому фон виден. Если так — дело в подаче (отступ/подсказка), а не в отрисовке.
